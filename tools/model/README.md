Scripts that generate the trap model (Blender 4.x+/bpy). Not needed to build or play the mod.
  python atlas.py SimpleFishingTrap_Albedo.png    -> 256px texture atlas
  python build_trap.py -- out                      -> OBJ + preview renders + icon
Sizes are at the top of build_trap.py (CHEST_W/CHEST_H, STAKE_W, strand counts).
